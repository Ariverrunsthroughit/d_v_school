# Projects — 프로젝트 작업대

## 목적과 역할
마감일과 완료 조건이 있는 **진행 중 프로젝트**를 다루는 작업대. 지식을 쌓는 곳(Zettelkasten)과 분리해, "무언가를 끝내는 일"만 둔다.

## 들어가는 노트
- 프로젝트별 하위 폴더 `Projects/프로젝트명/` (개요, 할 일, 회의록, 산출물 초안)
- 모든 프로젝트 노트는 프로젝트 개요 노트(`00. 개요`)에서 시작

## 규칙
- 프로젝트 = 목표 + 마감일 + 완료 조건. 셋 중 하나라도 없으면 `Areas/`로 보낸다.
- frontmatter: `type: project`, `deadline: YYYY-MM-DD`, `status: 진행중|보류|완료`
- 프로젝트에서 얻은 재사용 가능한 통찰은 `Zettelkasten/00. Inbox/`로 보내 영구 노트로 키운다.
- 완료되면 폴더째 `Archive/`로 이동한다.
